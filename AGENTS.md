# b14-a8-cat_harry

Next.js 16 + React 19 App Router project. No tests, no CI, no backend yet — single route `/` (`src/app/page.tsx`).

## Commands

- `npm run dev` — Turbopack dev server on :3000. Turbopack is the default bundler for dev and build here (webpack is an opt-out).
- Verify changes: `npx next typegen; npx tsc --noEmit` then `npm run build`; `npm run lint` for ESLint. There are no test or typecheck scripts — and bare `tsc` misses route types until typegen runs.
- Add UI with `npx shadcn add <name>` (shadcn CLI is a local dep).

## Next.js 16 quirks

- `PageProps<'/route'>` / `LayoutProps<'/route'>` are global type helpers — no import needed. Their types are generated by `next dev` / `next build` / `npx next typegen`, so a new route is untyped until one of those runs.
- Tailwind v4 is loaded as a `turbopack.rules` CSS loader in `next.config.ts` (there is no `postcss.config.mjs`). Don't add PostCSS or Tailwind config files.
- Theme tokens (colors, radii, dark variant) live in `src/app/globals.css` (`@theme inline` + OKLCH CSS variables + `.dark` custom variant). Tailwind v4 — there is no `tailwind.config` to edit.

## React Compiler

- `reactCompiler: true` in `next.config.ts`. Write plain React; don't add `useMemo`/`useCallback`/`React.memo` for performance — the compiler memoizes automatically.

## UI stack: shadcn `base-nova` on Base UI

- `components.json` style is `base-nova`: `src/components/ui/*` wrap `@base-ui/react` primitives, **not** Radix. Don't write Radix-based shadcn code from memory — use the CLI or copy a neighboring `src/components/ui` file.
- `cn` is the npm package `cn` — shadcn's official clsx + tailwind-merge replacement, re-exported via `src/lib/utils.ts`. Don't rewrite `utils.ts` the classic way (`tailwind-merge` isn't installed).
- `src/components/ui` and `src/hooks` hold many registry components installed ahead of use — search them before building UI from scratch.

## Misc

- `README.md` is untouched create-next-app boilerplate: it claims a Geist font and `app/page.tsx`; the real layout uses Josefin Sans and code lives in `src/`.
